# Pilot, governance and value model

## Proposed pilot scope
- Five strategic seafood suppliers.
- One manufacturing line.
- Two or three Bento export batches.
- Flow: supplier portal → ERP ESG record → batch QR traceability.

## Proposed success criteria
| KPI | Target in report |
| --- | --- |
| Supplier portal usage | 90% |
| Data accuracy | >95% |
| QR functionality | 100% |
| Production disruption | <5% |

## Financial assumptions
The source estimates VND 25.98bn project cost and VND 51.1bn benefit; modeled ROI is 96.69%. It includes technical investment, operations and assumed revenue/interest savings. This is a **business-case forecast**, not empirical ROI.

## Implementation risks
Supplier participation, integration complexity, poor data quality, changing regulation and disruption during migration.

**Source:** Business Case §§7–8, physical PDF pages 42–59.
